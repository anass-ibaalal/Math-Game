# Math Game - C++ Console Application

An interactive math training game developed in C++ that generates random arithmetic problems based on user-selected difficulty levels and operation types.

## Features
- **4 Difficulty Levels**: Easy (1-10), Medium (11-50), Hard (51-100), and Mixed Levels.
- **5 Operation Types**: Addition (+), Subtraction (-), Multiplication (x), Division (/), and Mixed Operations.
- **Colorized Terminal Output**: ANSI escape codes providing green feedback for correct answers and red for mistakes.
- **Game Performance Summary**: Detailed round breakdown displaying correct vs. wrong answers and final Pass/Fail status.
- **Custom Round Size**: Choose anywhere from 1 to 100 questions per game.
